# Pasta de Imagens

Esta pasta contém todas as imagens utilizadas no projeto MyONG.

## Estrutura

- **logo.png** - Logo da plataforma MyONG
- **hero-banner.jpg** - Imagem de fundo da seção hero
- **project-*.jpg** - Imagens dos projetos (1 a 6)
- **icons/** - Pasta contendo os ícones SVG

## Imagens Necessárias

### Logo (logo.png)
- Dimensões recomendadas: 200x200px
- Formato: PNG com fundo transparente
- Cores: Verde (#2E8B57) e/ou Laranja (#FF6B35)

### Hero Banner (hero-banner.jpg)
- Dimensões recomendadas: 1920x600px
- Formato: JPG
- Tema: Imagem inspiradora relacionada a voluntariado, comunidade ou ação social

### Imagens de Projetos (project-1.jpg a project-6.jpg)
- Dimensões recomendadas: 800x600px
- Formato: JPG
- Tema: Imagens representando cada categoria de projeto

## Ícones SVG Necessários

Na pasta `icons/`, temos os seguintes ícones SVG:

- **search.svg** - Ícone de busca/lupa
- **volunteer.svg** - Ícone de voluntário/pessoa
- **donate.svg** - Ícone de doação/coração ou mão
- **facebook.svg** - Logo do Facebook
- **instagram.svg** - Logo do Instagram
- **linkedin.svg** - Logo do LinkedIn
- **twitter.svg** - Logo do Twitter

## Especificações dos Ícones

- **Formato**: SVG (Scalable Vector Graphics)
- **Tamanho**: 24x24px ou 32x32px (viewBox)
- **Cor padrão**: Preto (#000000) ou transparente
- **Otimização**: Minimizar código SVG

## Fontes de Imagens Gratuitas

Neste projeto utilizamos imagens de bancos gratuitos como:

- [Unsplash](https://unsplash.com) - Fotos de alta qualidade
- [Pexels](https://pexels.com) - Fotos e vídeos gratuitos
- [Pixabay](https://pixabay.com) - Imagens e ilustrações
- [Flaticon](https://flaticon.com) - Ícones SVG gratuitos
- [Font Awesome](https://fontawesome.com) - Biblioteca de ícones

## Otimização

Antes de adicionar as imagens ao projeto:

1. Reduza o tamanho dos arquivos sem perder qualidade
2. Use ferramentas como TinyPNG ou Squoosh
3. Mantenha proporção 16:9 para banners
4. Converta para formatos modernos (WebP) quando possível

**Nota**: As imagens não estão incluídas no repositório para reduzir o tamanho. Adicione suas próprias imagens seguindo as especificações acima.
