## 📋 Sobre o Projeto

Plataforma web completa desenvolvida para ONGs gerenciarem suas atividades, divulgar projetos, captar recursos e engajar voluntários. Uma solução digital profissional para o terceiro setor brasileiro.

## 🚀 Funcionalidades

- **Página Institucional** - Apresentação da organização e transparência
- **Gestão de Projetos** - Divulgação de iniciativas sociais
- **Portal de Voluntários** - Sistema de cadastro e engajamento
- **Captação de Recursos** - Campanhas e doações online
- **Design Responsivo** - Mobile-first e acessível

## 🛠️ Tecnologias

- HTML5 Semântico
- CSS3 Avançado (Grid, Flexbox, Variables)
- JavaScript Vanilla
- Design System Customizado
- Validações e Máscaras de Input

## 🔧 Como Executar

1. Clone o repositório:
```bash
git clone https://github.com/seu-usuario/myong.git
```

2. Acesse a pasta do projeto:
```bash
cd myong
```

3. Abra o arquivo `index.html` em seu navegador
